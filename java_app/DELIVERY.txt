📦 COSA È STATO CREATO
═════════════════════════════════════════════════════════════════════

Una APPLICAZIONE JAVA COMPLETA con GUI per automatizzare l'estrazione
di dati da PDF (Bolla_Consegna.pdf e Distinta.pdf) e popolare 
automaticamente il file Excel (0289 PAM PD ASPETTI TOTALIZZATORI S2.xlsx).


🎯 FUNZIONAMENTO
═════════════════════════════════════════════════════════════════════

INGRESSO:  PDF (Bolla_Consegna.pdf / Distinta.pdf)
           ↓
    Estrazione automatica:
    • Quantità (Q.C.)
    • Prezzo (Lordo)
    • Data documento
    • Giorno della settimana
           ↓
USCITA:   Excel aggiornato
          (0289 PAM PD ASPETTI TOTALIZZATORI S2.xlsx)
          Sheet Lun-Dom, sezioni INVIO/RESO populate
