📦 COSA HAI RICEVUTO
═══════════════════════════════════════════════════════════════════

Una APPLICAZIONE JAVA COMPLETA che estrae automaticamente dati 
da PDF (Bolla_Consegna.pdf e Distinta.pdf) e li popola nel file 
Excel (0289 PAM PD ASPETTI TOTALIZZATORI S2.xlsx).

Estrae automaticamente:
  • Quantità (Q.C.)
  • Prezzo (Lordo)
  • Data documento
  • Giorno della settimana
  • Tipo documento (Bolla/Distinta)

Popola automaticamente:
  • Sheet giornaliero (Lun, Mar, Mer, ecc.)
  • Sezione INVIO QUOTIDIANI
  • Sezione RESO QUOTIDIANI
  • Preserva formule Excel

📁 STRUTTURA CARTELLE
═══════════════════════════════════════════════════════════════════

f:\PAM\java_app\

  src\
    ├── MainWindow.java            ← GUI (finestra applicazione)

  build\                           ← Compilazione (temporaneo)

  compile.bat                      ← Compilazione
  download_libraries.bat           ← Scarica dipendenze
  test_environment.bat             ← Verifica ambiente

  README.md                        ← Manuale completo
  QUICKSTART.md                    ← Guida rapida

  START_HERE.txt                   ← Questo file

🚀 COME INIZIARE - 4 STEP
═══════════════════════════════════════════════════════════════════

STEP 1: VERIFICA AMBIENTE (2 minuti)
──────────────────────────────────────
Doppio click su:
  test_environment.bat

Questo verifica che Java e Python siano disponibili.

Output atteso: "SUCCESS - Tutti i test passati!"


STEP 2: SCARICA LIBRERIE (2-3 minuti)
──────────────────────────────────────
Doppio click su:
  download_libraries.bat

Questo scarica le librerie Apache POI necessarie.

Output atteso: "OK - Tutte le librerie scaricate correttamente!"


STEP 3: COMPILA (30 secondi)
──────────────────────────────
Doppio click su:
  compile.bat

Questo compila il codice Java e crea il JAR eseguibile.

Output atteso: "OK - Compilazione completata!"

Verifica: controlla che esista il file:
  dist\PAM-PDF-to-Excel.jar


STEP 4: USA L'APP (quotidiano)
───────────────────────────────
Doppio click su:
  run.bat

Finestra con GUI:
  1. Clicca "Seleziona PDF" 📁
  2. Scegli il PDF (Bolla o Distinta)
  3. Clicca "Elabora" ⚙️
  4. Attendi ~5 secondi
  5. Messaggio "✅ Completato!" oppure "❌ Errore"
