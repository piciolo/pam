# QUICKSTART - PAM PDF to Excel

## ⚡ In 3 Step

### Step 1️⃣: Scarica Librerie (UNA VOLTA)
```
Doppio click su: download_libraries.bat
```
Aspetta il completamento (2-3 minuti)

### Step 2️⃣: Compila (UNA VOLTA)
```
Doppio click su: compile.bat
```
Aspetta il completamento (30 secondi)

### Step 3️⃣: USA L'APP
```
Doppio click su: run.bat
```

## 📋 Procedure

### Uso Normale
1. Apri `run.bat`
2. Clicca "Seleziona PDF"
3. Scegli il PDF (Bolla_Consegna.pdf o Distinta.pdf)
4. Clicca "Elabora"
5. Attendi il messaggio di successo ✅

### Processo Batch (Più file)
```
Per ogni documento:
  1. run.bat
  2. Seleziona PDF
  3. Clicca Elabora
  4. Chiudi finestra
  5. Ripeti
```

## ⚠️ Problemi Comuni

| Problema | Soluzione |
|----------|-----------|
| "JAR non trovato" | Esegui `compile.bat` |
| "Librerie non trovate" | Esegui `download_libraries.bat` |
| "PDF non estratto" | Verifica che PDF abbia tabella dati |
| "Excel non aggiornato" | Chiudi Excel prima di elaborare |
| "Errore generico" | Leggi il messaggio nella finestra |
